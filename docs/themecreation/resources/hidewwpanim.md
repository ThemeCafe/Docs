This is a template that helps you add an animation to hide the Wara Wara Plaza screen.

[WWP Animation Template.zip](files/hidewwpanim/WWP Animation Template.zip){ .md-button .md-button--primary }

This zip file includes an empty template in `without animation/Men2.bps` and a template with an animation already applied as an example `Men2.bps`.

### Adding your frames

The animation is located in `Common > Layout > LoungeScaleMeter.szs`.

If you are using the example animation, you will have to [replace your frames](../general/textures.md#for-bflyt), if you are using the empty template you will have to [add your frames](../general/textures.md#for-bflyt_1) and change the texture of each material to the frame you want, and when importing the frames make sure to use `T_BC1_UNORM`.

!!! note "Notes"

    - If you want to use this kind of animation in a different theme, export the file `LoungeScaleMeter.szs` from this template and replace it in the theme you want to use it.
    - The recommended resolution for your frames is 480p, however keep in mind the memory usage of your theme.
